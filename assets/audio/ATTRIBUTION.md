# Audio attribution

Every file in this directory is **original content generated by this
repository** — `tools/generate_audio.gd` synthesizes all samples
procedurally (sine voices, deterministic value noise, exponential envelopes).
No external recordings, sample packs or licensed material are bundled.

- Regenerate with: `godot --headless --path . --script res://tools/generate_audio.gd`
- Format: 16-bit PCM mono, 22050 Hz. `music_*.wav` loops are seamless by
  construction (voice frequencies complete integer cycles per loop; envelopes
  are periodic with the loop length).
- The same generation policy as the SpriteCook pixel art recorded in
  `assets/art/exploration/spritecook-assets.json`: in-repo generated, no
  third-party attribution required beyond this note.
