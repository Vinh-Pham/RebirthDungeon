## Description

|                                                                                                                                            |                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [![Bow Mastery.png](https://wiki.mabinogiworld.com/images/c/c0/Bow_Mastery.png)](https://wiki.mabinogiworld.com/view/File:Bow_Mastery.png) | The [bow](https://wiki.mabinogiworld.com/view/Bows_List 'Bows List') is an iconic ranged weapon. Bow Mastery skill training will allow you to deal more damage with a bow. As you learn this skill, your goal is to become proficient with the bow and increase your damage. |

## Details

- Passively increases the player's minimum and maximum ranged [Damage](https://wiki.mabinogiworld.com/view/Damage 'Damage') when using [bow](https://wiki.mabinogiworld.com/view/Bows_List 'Bows List') weapons.

    - These changes do not show on the weapon.

- [Giants](https://wiki.mabinogiworld.com/view/Giant 'Giant') cannot learn this skill due to the inability to wield Bows.
