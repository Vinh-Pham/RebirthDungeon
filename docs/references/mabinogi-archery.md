# Archery (Talent) [![mini](https://wiki.mabinogiworld.com/skins/common/images/mw/mini.png)](https://mabi.world/w45mu)

From Mabinogi World Wiki

## Website Description

_The Archery talent focuses on using precise ranged attacks to subdue enemies from a distance. It emphasizes fighting with ranged weapons, such as bows and crossbows. When Archery is your active Talent, you'll gain Dexterity more quickly. You'll also earn more EXP for Archery skills._

## Description

The archery talent focuses on taking out the enemy from afar with either a Bow or a Crossbow. Elves may mount a [Pet](https://wiki.mabinogiworld.com/view/Pet "Pet") which can do combat in order to shoot arrows, and may run while a skill is loaded.

This talent is unavailable to Giant characters.

**Talent Title**: Archer
